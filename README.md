# avia-connectivity-forecast
Прогнозирование пассажирских авиапотоков на основе нейросетевых алгоритмов для оценки транспортной связанности территорий страны (Predicting passenger air traffic based on neural network algorithms to assess the transport connectivity of the country’s territories).

## О проекте

**Цель:** разработка методики и прототипа системы для прогнозирования авиапотоков и оценки транспортной связанности территорий РФ.
**Задачи:**
- Провести аналитический обзор методов прогнозирования транспортных потоков и оценки связанности;
- Сформировать датасет авиапассажиропотоков по 50 ключевым городам РФ за 2014-2025 гг.;
- Разработать и обучить нейросетевые модели, сравнить их и выбрать наилучшую;
- Разработать сценарный подход к прогнозированию на основе демографических и экономических факторов;
- Разработать методику расчёта гибридного индекса транспортной связанности на основе гравитационной модели и сетевых метрик;
- Разработать интерактивное приложение на Streamlit для визуализации прогнозов и индекса связанности.
